## 🔧 Что было исправлено

### 1. Атомарная проверка и установка блокировки (Проблема #4)

**Файл:** `server/src/utils/engineerTeam.ts`

**Изменение:**
```typescript
// Было: Проверка и установка в отдельные операции
const visit = await prisma.visit.findUnique(...);
if (visit.editingEngineerId) return { canEdit: false };
await prisma.visit.update(...);

// Стало: Атомарная операция через транзакцию
const result = await prisma.$transaction(async (tx) => {
  const visit = await tx.visit.findUnique(...);
  if (visit.editingEngineerId) return { canEdit: false };
  await tx.visit.update(...);
  return { canEdit: true };
});
```

**Результат:** Два инженера не могут одновременно получить блокировку.
