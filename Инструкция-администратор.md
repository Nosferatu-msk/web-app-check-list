## 1. Введение

Администратор — пользователь с полным доступом к системе. Вы управляете справочниками, пользователями, привязками оборудования к объектам, контролируете все визиты и формируете отчёты.

### 1.1. Ваши возможности

| Функция | Описание |
|---------|----------|
| Управление пользователями | Создание, редактирование, блокировка учётных записей |
| Справочники | Адреса, виды оборудования, типы помещений, рекомендации, производители, модели |
| Привязка оборудования | Управление связью «объект — оборудование» |
| Модерация | Утверждение/отклонение предложений инженеров |
| Импорт | Массовая загрузка данных из CSV и XLSX |
| Визиты | Просмотр всех визитов, формирование отчётов |
| Заявки | Импорт внешних заявок, назначение инженеров |

## 2. Вход в систему

1. Откройте приложение в браузере.
2. Введите **email** и **пароль** администратора.
3. Нажмите **«Войти»**.

### 2.1. Восстановление пароля

Нажмите **«Забыли пароль?»** на экране входа — на email придёт ссылка для сброса.

## 3. Управление пользователями

Перейдите в раздел **«Администрирование» → «Пользователи»**.

### 3.1. Создание пользователя

1. Нажмите **«+ Создать пользователя»**.
2. Заполните:
   - **ФИО** — обязательно
   - **Email** — обязательно (используется для входа)
   - **Роль** — Инженер / Территориальный менеджер / Администратор
   - **Специализация** (только для инженеров) — чекбоксы: ВиК, ИСЖ, ГПМ, ДГУ, ИБП. По умолчанию выбрана ИСЖ.
3. Задайте временный пароль или система сгенерирует автоматически.
4. Нажмите **«Создать»**.

> **Примечание:** При смене роли с инженера на ТМ или Администратора специализация сбрасывается.

### 3.2. Редактирование пользователя

1. Найдите пользователя в таблице (поиск по ФИО или email — частичное совпадение, без учёта регистра).
2. Нажмите на строку — откроется форма редактирования.
3. Измените нужные поля:
   - ФИО, email
   - Роль
   - Специализация (для инженеров)
   - Статус (активен / заблокирован)
4. Нажмите **«Сохранить»**.

### 3.3. Блокировка пользователя

Установите статус «Заблокирован» — пользователь не сможет войти в систему. Данные и история визитов сохраняются.

### 3.4. Поиск пользователей

Над таблицей расположена строка поиска:
- Поиск по ФИО и email
- Частичное совпадение (ввели «иван» — найдёт «Иванов»)
- Без учёта регистра
- Автоматическая задержка 300 мс (не нужно ждать после ввода)
- Отображается до 50 записей

### 3.5. Колонка «Спец.»

В таблице пользователей отображается колонка «Спец.» с текущей специализацией инженера (например, «ИСЖ, ВиК»).

## 4. Справочник адресов (объектов)

Перейдите в раздел **«Администрирование» → «Адреса»**.

### 4.1. Просмотр адресов

Таблица содержит: город, улица, дом, строение, полный адрес, аналитический код объекта, email заказчика.

### 4.2. Добавление адреса

1. Нажмите **«+ Добавить адрес»**.
2. Заполните:
   - **Город** — обязательно
   - **Улица** — обязательно
   - **Дом** — обязательно
   - **Строение/корпус** — опционально
   - **Аналитический код объекта** — уникальный, формат `RU/77/001`
   - **Email заказчика** — опционально (используется для отправки отчётов)
3. Полный адрес формируется автоматически.
4. Нажмите **«Сохранить»**.

### 4.3. Редактирование адреса

Нажмите на адрес в таблице — откроется форма. Измените поля и сохраните.

### 4.4. Удаление адреса (мягкое)

Нажмите **«Удалить»** — адрес будет помечен как удалённый (`is_deleted`). Он скроется из списков и поиска, но сохранится для исторических визитов и связанных записей. Физического удаления не происходит.

## 5. Привязка «Объект — Оборудование»

Перейдите в раздел **«Администрирование» → «Оборудование объектов»**.

### 5.1. Назначение

Этот модуль хранит информацию о том, какое оборудование физически установлено на каждом объекте. При создании визита инженер видит это оборудование и может добавить его в чек-лист без ручного ввода.

### 5.2. Просмотр привязок

1. Выберите **адрес объекта** из справочника.
2. Отобразится список привязанного оборудования:
   - Вид оборудования
   - Помещение (или «⚠️ Не указано»)
   - Марка, модель
   - Серийный номер
   - Описание расположения
   - Статус (активно / деактивировано)

### 5.3. Добавление оборудования к объекту

1. Нажмите **«+ Добавить оборудование»**.
2. Заполните:
   - **Вид оборудования** — из справочника
   - **Тип помещения** — из справочника (опционально)
   - **Марка** — текстовое поле (опционально)
   - **Модель** — текстовое поле (опционально)
   - **Серийный номер** — текстовое поле (опционально)
   - **Описание расположения** — где установлено на объекте (опционально)
   - **Наружный блок** — отметьте, если это наружный блок кондиционера
3. Нажмите **«Сохранить»**.

### 5.4. Деактивация оборудования

Нажмите **«Деактивировать»** — запись скроется из списков инженера, но сохранится для истории визитов. Физического удаления не происходит.

### 5.5. Уникальность

Система контролирует:
- Одна и та же единица оборудования (по серийному номеру) не может быть привязана к объекту дважды
- Для записей без серийного номера уникальность обеспечивается по описанию расположения

## 6. Справочник видов оборудования

Перейдите в раздел **«Администрирование» → «Виды оборудования»**.

### 6.1. Просмотр

Таблица содержит все виды оборудования (39 записей: 38 активных + 1 деактивированный `vent`).

Для каждого вида отображается:
- Наименование
- Код (транслит, для маркировки фото)
- Количество требуемых фото (1 или 2)
- Требуемая специализация (ВиК, ИСЖ, ГПМ, ДГУ, ИБП)
- Статус (активен / деактивирован)

### 6.2. Редактирование

Нажмите на вид оборудования — откроется форма. Можно изменить:
- Наименование
- Код
- Количество фото
- Требуемую специализацию
- Статус (активен / деактивирован)

### 6.3. Контролируемые параметры

Для каждого вида оборудования можно настроить набор контролируемых параметров (поля, которые инженер заполняет при осмотре).

## 7. Справочник типов помещений

Перейдите в раздел **«Администрирование» → «Типы помещений»**.

### 7.1. Просмотр

Таблица содержит типы помещений:
- Электрощитовая, Серверная, Клиентский зал, Комната приёма пищи, Санузел, Кровля, Фасад, Зона самообслуживания, Крыльцо, Тепловой узел, Касса, КХЦ и др.

### 7.2. Добавление типа помещения

1. Нажмите **«+ Добавить»**.
2. Укажите **наименование** и **код** (транслит, для маркировки фото).
3. Нажмите **«Сохранить»**.

### 7.3. Редактирование и удаление

Нажмите на запись для редактирования. Удаление доступно, если тип не используется в привязках.

## 8. Справочник типовых рекомендаций

Перейдите в раздел **«Администрирование» → «Рекомендации»**.

### 8.1. Структура

Каждая рекомендация привязана к виду оборудования и содержит текст. Рекомендации отображаются инженеру в виде чекбоксов — не нужно печатать текст вручную.

### 8.2. Добавление рекомендации

1. Нажмите **«+ Добавить рекомендацию»**.
2. Заполните:
   - **Вид оборудования** — к какому виду относится
   - **Текст рекомендации** — что писать в отчёте
   - **Порядок отображения** — число для сортировки
3. Нажмите **«Сохранить»**.

### 8.3. Редактирование и деактивация

Нажмите на рекомендацию для редактирования. Можно деактивировать — рекомендация скроется из списков инженера, но сохранится в уже созданных визитах.

### 8.4. Фильтрация

Рекомендации можно фильтровать по виду оборудования для удобства навигации.

### 9.1. Просмотр

Таблица содержит производителей оборудования (название, страна). Поддерживается пагинация и поиск по названию.

### 9.2. Добавление производителя

3. Нажмите **«Сохранить»**.

### 9.3. Деактивация

## 10. Справочник моделей оборудования

Перейдите в раздел **«Администрирование» → «Модели»**.

### 10.1. Структура

Каждая модель привязана к виду оборудования и производителю. Модели проходят модерацию: инженер может предложить новую модель, администратор утверждает или отклоняет.

### 10.2. Просмотр

Таблица с фильтрами:
- По статусу (утверждённые / на рассмотрении / отклонённые)
- По виду оборудования
- По производителю

### 10.3. Создание модели

1. Нажмите **«+ Добавить модель»**.
2. Укажите вид оборудования, производителя и название модели.
3. Полное название формируется автоматически: «Производитель + Модель».
4. Нажмите **«Сохранить»**.

### 10.4. Модерация предложенных моделей

Инженеры могут предлагать новые модели через интерфейс визита. Такие модели создаются со статусом `pending`.

1. Откройте фильтр «На рассмотрении».
2. Просмотрите предложенную модель.
3. Нажмите **«Утвердить»** или **«Отклонить»** (с указанием причины).

## 11. Утверждение предложений оборудования

Перейдите в раздел **«Администрирование» → «Предложения оборудования»**.

### 11.1. Назначение

Инженеры могут обнаруживать на объектах оборудование, которое ещё не привязано, и предлагать добавить его. Вы рассматриваете эти предложения.

### 11.2. Список предложений

Отображаются предложения со статусом `pending` (на рассмотрении):
- Инженер, предложивший оборудование
- Адрес объекта
- Вид оборудования
- Помещение
- Марка, модель, серийный номер
- Описание расположения

### 11.3. Утверждение

1. Откройте предложение.
2. Проверьте данные.
3. Нажмите **«Утвердить»**.
4. Оборудование автоматически добавляется в привязку объекта (`object_equipment`) со статусом `is_active = true`.

### 11.4. Отклонение

1. Нажмите **«Отклонить»**.
2. Укажите причину отклонения (опционально).
3. Статус предложения меняется на `rejected`.

## 12. Модерация привязки оборудования к помещениям

### 12.1. Дашборд модерации

Перейдите в раздел **«Администрирование» → «Модерация»**. Отобразится дашборд с фильтрами:
- **Тип запроса** — перенос между помещениями / новое оборудование
- **Объект** — фильтр по адресу
- **Инженер** — кто предложил
- **Истекающие скоро** — предложения с приближающимся сроком (30 дней)

### 12.2. Типы запросов

| Тип | Описание |
|-----|----------|
| **Перенос оборудования** | Инженер перенёс оборудование из одного помещения в другое. Помещение обновлено немедленно, требуется ваше подтверждение. |
| **Новое оборудование** | Инженер добавил оборудование, которого нет в привязке. Создаётся после вашего утверждения. |

### 12.3. Действия

- **Подтвердить** — изменения вступают в силу окончательно
- **Отклонить** — при переносе: помещение откатывается на прежнее; при новом оборудовании: запись деактивируется
- **Массовые действия** — подтвердите или отклоните несколько записей одновременно

### 12.4. Автоматическое удаление (TTL)

Неподтверждённые предложения автоматически деактивируются через 30 дней (cron-задача выполняется ежедневно в 03:00):
- Переносы помещений — откатываются
- Новое оборудование — деактивируется
- Инженеры получают уведомления об истечении срока

## 13. Массовый импорт данных

Перейдите в раздел **«Администрирование» → «Импорт»**.

### 13.1. Поддерживаемые форматы

- **CSV** — разделители `,` и `;`, кодировки UTF-8 / Windows-1251 (автоопределение)
- **XLSX** — Microsoft Excel 2007+, первый лист, первая строка — заголовки

### 13.2. Ограничения

- До 20 000 строк за один импорт
- Размер файла до 10 МБ

### 13.3. Типы импорта

| Тип данных | Формат | Описание |
|------------|--------|----------|
| **Адреса** | CSV/XLSX | Город, улица, дом, строение, код объекта, email |
| **Оборудование объектов** | CSV/XLSX | Адрес, вид оборудования, помещение, марка, модель, SN |
| **Рекомендации** | CSV/XLSX | Вид оборудования, текст рекомендации |
| **Пользователи** | CSV/XLSX | ФИО, email, роль. Пароли генерируются автоматически и отправляются на email |
| **Производители** | CSV | name, country |
| **Модели оборудования** | CSV | eq_type, manufacture, model |

### 13.4. Процесс импорта

1. Выберите тип данных для импорта.
2. Загрузите файл.
3. Система выполнит **предварительную валидацию** (pre-validation):
   - Проверка формата файла
   - Проверка обязательных полей
   - Проверка дубликатов
   - Сопоставление со справочниками
4. Если есть ошибки — отобразится модальное окно со списком ошибок и номерами строк.
5. При отсутствии ошибок — подтвердите импорт.

### 13.5. Импорт пользователей

При импорте пользователей:
- Пароли генерируются автоматически
- Каждый пользователь получает email с временным паролем и инструкцией
- Роль по умолчанию — «Инженер»

## 14. Управление привязками ТМ

Перейдите в раздел **«Администрирование» → «Привязки ТМ»**.

### 14.1. Привязка ТМ к объектам

Назначьте территориального менеджера к определённым объектам (адресам):
1. Выберите ТМ из списка.
2. Отметьте объекты, которые закрепляются за ним.
3. Нажмите **«Сохранить»**.

### 14.2. Привязка ТМ к инженерам

Назначьте инженеров, подчинённых конкретному ТМ:
1. Выберите ТМ.
2. Отметьте инженеров.
3. Нажмите **«Сохранить»**.

ТМ будет видеть визиты только своих инженеров и отчёты только по своим объектам.

## 15. Просмотр всех визитов

Перейдите в раздел **«Визиты»**.

### 15.1. Фильтрация

- **По инженеру** — выберите конкретного инженера
- **По объекту** — выберите адрес
- **По статусу** — запланированные, в работе, завершённые, отправленные, исправленные ТМ
- **По периоду** — диапазон дат

### 15.2. Действия

- **Просмотр** — нажмите на визит для просмотра деталей
- **Редактирование** — внесите изменения в параметры задач
- **Удаление** — мягкое удаление (визит скрывается, данные сохраняются)
- **Формирование отчёта** — создайте PDF + ZIP

## 16. Формирование отчётов

### 16.1. Отчёт по отдельному визиту

1. Откройте визит.
2. Нажмите **«Сформировать отчёт»**.
3. PDF-отчёт и ZIP-архив будут созданы.
4. Отправьте по email или скачайте.

### 16.2. Сводный отчёт за период

1. Перейдите в раздел **«Отчёты»**.
2. Выберите **«Сводный отчёт за период»**.
3. Укажите дату начала и дату окончания.
4. Нажмите **«Сформировать»**.

Структура: титульный лист → группировка по объектам → визиты с задачами, параметрами и фотографиями.

### 16.3. Отчёт по объектам

1. Выберите **«Отчёт по объектам»**.
2. Отметьте галочками нужные объекты.
3. Укажите период.
4. Нажмите **«Сформировать»**.

### 16.4. Прикрепление сканов актов

К сводным отчётам можно приложить сканы подписанных актов (JPG/PNG/PDF, до 10 файлов, до 50 МБ). Они автоматически включаются в итоговый PDF.

## 20. Часто задаваемые вопросы

### Как восстановить удалённый адрес?
Адрес помечается как удалённый (мягкое удаление). Обратитесь к базе данных или свяжитесь с разработчиком для восстановления.

### Что будет, если деактивировать вид оборудования?
Вид скроется из справочника и модальных окон инженера. Ранее созданные задачи с этим видом сохранятся в визитах и отчётах.

### Можно ли массово загрузить 230 адресов?
Да, используйте импорт из CSV или XLSX. Подготовьте файл с колонками: город, улица, дом, строение, код объекта, email. Загрузите через «Администрирование» → «Импорт» → «Адреса».

### Как узнать, какие предложения инженеров ожидают рассмотрения?
Перейдите в «Администрирование» → «Предложения оборудования» или «Модерация». Непрочитанные уведомления также отображаются на колокольчике.

### Что происходит с неподтверждёнными предложениями через 30 дней?
Они автоматически деактивируются cron-задачей (ежедневно в 03:00). Инженеры получают уведомления об истечении срока.

### Как привязать ТМ к группе инженеров и объектов?
Перейдите в «Администрирование» → «Привязки ТМ». Выберите ТМ и отметьте инженеров и объекты.

### Можно ли изменить email заказчика после создания адреса?
Да, откройте адрес в справочнике и измените поле «Email заказчика». Новое значение будет использоваться при отправке отчётов.

### Как посмотреть журнал действий пользователей?
Система ведёт аудит всех значимых действий (создание, редактирование, удаление). Обратитесь к разработчику для доступа к журналу аудита.
