♿ Доступность

Каждый интерактивный элемент имеет accessibilityLabel, role и hint.

§4 a11y · WCAG 2.2 AA · TalkBack · 48dp touch
Пример: кнопка «Добавить оборудование»
<Pressable accessibilityLabel="Добавить оборудование" accessibilityRole="button" accessibilityHint="Открывает экран выбора оборудования" >
Чек-лист проверки:
✅ Контраст текста ≥ 4.5:1 (normal) / 3:1 (large)
✅ Touch targets ≥ 48×48dp
✅ Иконки + текст (не color alone)
✅ accessibilityLabel на каждой кнопке
✅ Семантические role: button, header, search
✅ prefers-reduced-motion respected
✅ Form labels связаны с inputs
✅ Error messages через role="alert"
