# Инструкция по публикации мобильного приложения в Google Play

## Предварительные требования

### 1. Google Play Developer Account
- **Стоимость:** $25 единоразово
- **Регистрация:** https://play.google.com/console/signup
- **Время активации:** 1-2 дня

### 2. EAS (Expo Application Services)
- **Регистрация:** `npx eas login` (или создать аккаунт на expo.dev)
- **Free tier:** 30 build-ов/месяц (достаточно для начала)

### 3. Графика для Google Play
- **Иконка:** 512x512 px (PNG)
- **Скриншоты:** Минимум 2, размер 1080x1920 или 1440x2560
- **Feature Graphic:** 1024x500 px (баннер для страницы приложения)
- **Описание:** Текстовое описание приложения (до 4000 символов)

## Пошаговая инструкция

### Шаг 1: Установка EAS CLI

```bash
npm install -g eas-cli
```

### Шаг 2: Авторизация в EAS

```bash
cd mobile
eas login
```

### Шаг 3: Инициализация проекта в EAS

```bash
eas init
```

Это создаст `projectId` в `app.json` и свяжет проект с Expo.

### Шаг 4: Создание иконок

Поместить в `mobile/assets/`:
- `icon.png` (1024x1024) — см. `assets/README.md`
- `adaptive-icon.png` (1024x1024)
- `splash.png` (1284x2778)

### Шаг 5: Сборка APK для тестирования

```bash
# Development build (для локального тестирования)
eas build --platform android --profile development

# Preview build (APK для распространения)
eas build --platform android --profile preview
```

После сборки EAS выдаст ссылку для скачивания APK.

### Шаг 6: Тестирование на устройстве

1. Скачать APK на Xiaomi Redmi Note 10 Pro
2. Разрешить установку из неизвестных источников
3. Установить APK
4. Протестировать основные сценарии:
   - Вход по логину/паролю
   - Настройка биометрии
   - Создание визита
   - Добавление задач
   - Съёмка фото
   - Офлайн-режим
   - Синхронизация
   - Формирование отчёта

### Шаг 7: Сборка AAB для Google Play

```bash
eas build --platform android --profile production
```

Результат: `.aab` файл (Android App Bundle).

### Шаг 8: Создание приложения в Google Play Console

1. Перейти на https://play.google.com/console
2. "Создать приложение"
3. Заполнить данные:
   - **Название:** Чек-лист инженера
   - **Язык по умолчанию:** Русский
   - **Приложение или игра:** Приложение
   - **Бесплатное или платное:** Бесплатное

4. Заполнить страницу в магазине:
   - **Краткое описание:** (до 80 символов)
     ```
     Мобильное приложение для инженеров ТО: визиты, задачи, фото, отчёты, офлайн-работа
     ```
   
   - **Полное описание:** (до 4000 символов)
     ```
     Цифровой чек-лист инженера — мобильное приложение для технического обслуживания оборудования.
     
     ОСНОВНЫЕ ФУНКЦИИ:
     • Создание и ведение визитов на объектах
     • Заполнение параметров оборудования (13 типов)
     • Фотофиксация ДО/ПОСЛЕ с нативной камерой
     • Офлайн-работа без потери данных
     • Автоматическая синхронизация при появлении сети
     • Формирование PDF-отчётов
     • Отправка отчётов по email
     
     БЕЗОПАСНОСТЬ:
     • Вход по биометрии (отпечаток/лицо)
     • PIN-код для экстренных случаев
     • Автоматическая блокировка при неактивности
     
     Для работы требуется аккаунт в системе "Цифровой чек-лист инженера".
     ```
   
   - **Иконка:** 512x512 px
   - **Скриншоты:** Минимум 2 (1080x1920)
   - **Feature Graphic:** 1024x500 px

5. Заполнить раздел "Контент":
   - Возрастные ограничения
   - Категория: Бизнес / Продуктивность
   - Контактные данные

### Шаг 9: Загрузка AAB в Google Play

1. Перейти в "Производство" → "Создать новое производство"
2. Загрузить `.aab` файл
3. Заполнить примечания к выпуску
4. Отправить на проверку

### Шаг 10: Внутреннее тестирование (Closed Testing)

1. В Google Play Console: "Тестирование" → "Внутреннее тестирование"
2. Добавить email тестировщиков (до 100)
3. Тестировщики получают ссылку для установки
4. Собрать обратную связь

### Шаг 11: Публикация

После успешного тестирования:
1. "Производство" → "Отправить на проверку"
2. Google проверит приложение (1-3 дня)
3. После одобрения — публикация в Google Play

## Обновления приложения

### OTA-обновления (EAS Update)
Для исправлений JS-кода без публикации в Google Play:

```bash
# Публикация OTA-обновления
eas update --branch production --message "Исправление бага"

# Проверка обновлений
eas update:list
```

### Полные обновления (через Google Play)
Для изменений нативного кода (камера, GPS, новые библиотеки):

```bash
# Собрать новую версию
eas build --platform android --profile production

# Загрузить в Google Play
eas submit --platform android
```

## Полезные команды

```bash
# Локальный запуск для разработки
cd mobile
npx expo start

# Сборка APK для тестирования
eas build --platform android --profile preview

# Сборка AAB для Google Play
eas build --platform android --profile production

# OTA-обновление
eas update --branch production --message "Описание изменений"

# Загрузка в Google Play
eas submit --platform android

# Просмотр статуса сборок
eas build:list
```
