### 2. Удалить дубликаты типов помещений в БД

```bash
docker compose -f docker-compose.prod.yml exec -T db psql -U checklist -d checklist << 'EOF'
UPDATE tasks SET room_type_id = (SELECT MIN(id) FROM room_types WHERE name = 'Комната приёма пищи') WHERE room_type_id IN (SELECT id FROM room_types WHERE name = 'Комната приёма пищи' AND id != (SELECT MIN(id) FROM room_types WHERE name = 'Комната приёма пищи'));
DELETE FROM room_types WHERE name = 'Комната приёма пищи' AND id != (SELECT MIN(id) FROM room_types WHERE name = 'Комната приёма пищи');
ALTER TABLE room_types ADD CONSTRAINT room_types_name_key UNIQUE (name);
EOF
```

### 3. Сгенерировать serialNumber для существующего оборудования

```bash

```

### 4. Собрать и перезапустить контейнеры

## Проверка после деплоя

1. **Уникальность типов помещений:**
   - Зайти в админ-панель → Справочники → Типы помещений
   - Проверить, что "Комната приёма пищи" только одна
   - Попробовать создать дубликат → должна появиться ошибка

2. **Отображение моделей:**
   - Создать визит → Добавить оборудование
   - Выбрать производителя (например, ИТЕЛМАН)
   - В списке моделей должно быть "ИТЕЛМАН СВ-15Г", а не "ИТЕЛМАН СВ-15Г (ИТЕЛМАН)"

3. **Серийные номера:**
   - Добавить прибор учёта (ХВС/ГВС/э/э) без serialNumber → ошибка
   - Добавить обычное оборудование без serialNumber → автогенерация
   - Проверить в БД: `SELECT id, serial_number FROM object_equipment WHERE serial_number IS NOT NULL LIMIT 10;`
