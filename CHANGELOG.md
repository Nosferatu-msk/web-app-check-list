# Changelog

## [2026-08-03]

### Новые функции
- **Управление специализацией видов оборудования** — администратор может назначать и изменять требуемую специализацию (ВиК, ИСЖ, ГПМ, ДГУ, ИБП) для каждого вида оборудования через админку. Добавлена колонка «Специализация» в таблицу видов оборудования (цветные теги) и поле Select в форме создания/редактирования. Пустое значение = доступно всем специализациям
- **Импорт специализации через CSV** — при импорте видов оборудования поддерживается колонка `specialization_req` (vik/iszh/gpm/dgu/ibp). Некорректные значения валидируются с ошибкой по строке

### Исправления
- **Фильтрация оборудования по специализации в модальном окне добавления** — эндпоинты `other-rooms` и `rooms` теперь фильтруют оборудование по специализации инженера. Ранее инженер видел оборудование из других помещений и список помещений без учёта своей специализации (например, инженер ВиК видел ИБП, кулеры и т.д.)
- **Пагинация на странице «Заявки»** — исправлен переход на вторую и последующие страницы. Обработчик `onChange` таблицы Ant Design вызывался и при смене страницы, и при сортировке, и всегда сбрасывал `page=1`. Теперь корректно различаются: смена страницы → сохранение номера, смена pageSize → сброс на 1, сортировка → сброс на 1.

## [2026-07-30]

### Новые функции
- **Множественное назначение инженеров** — ТМ может назначить более одного инженера на любую заявку (ранее только для ИСЖ/мультиспец.)
- **Сортировка заявок** — по клику на заголовки колонок: № заявки, Статус исполнения, Код объекта, Адрес (серверная сортировка, числовая для № и кода)
- **Фильтр по статусу исполнения** — Не назначена / Назначена / В работе / Завершена (вместо статуса импорта)
- **Фильтр по инженеру** — выпадающий список с поиском на странице заявок
- **Периметр ТМ** — ТМ видит только заявки по своим адресам, назначенные на своих инженеров (или неназначенные)

### Улучшения UI
- **Оптимизация страницы заявок (ПК)** — ширина контейнера 1400px, компактные колонки, иконки в действиях, пагинация по 10 записей
- **Единая ширина всех страниц** — все страницы ТМ/Админа (Визиты, Отчёты, Профиль, Админ-панель) имеют maxWidth 1400px
- **Отображение инженеров** — в списке заявок теперь показываются назначенные инженеры (ранее всегда «Не назначен»)

### Исправления
- Убрана кнопка «Отчёты» из нижней навигации инженера (доступ запрещён)
- PWA-баннер обновления — белая кнопка с синим текстом для контраста на тёмном фоне
- Атрибут `capture="environment"` на кнопке камеры (PhotoPage)
- Исправлена видимость PWA-баннера на мобильных

## [2026-07-29]

### Новые функции
- **Создание помещения из визита** — инженер может создать новое помещение и перенести оборудование прямо в модальном окне добавления оборудования
- **Перенос оборудования между помещениями** — видно всё оборудование объекта (из всех помещений), а не только уровень объекта
- **Импорт по названиям** — оборудование и типы помещений в CSV можно указывать по имени (не только по коду)
- **PWA-баннер обновления** — уведомление о новой версии с кнопкой обновления
- **Обновление данных при фокусе** — автоматическая перезагрузка данных при переключении на вкладку браузера
- **Поиск и мульти-фильтр визитов** — поиск по адресу/коду, фильтр по нескольким статусам, переключатель удалённых только для админа

### Исправления
- `room_type='Объект'` в CSV маппится на NULL (уровень объекта), а не создаёт помещение «Объект»
- Отображение кода адреса и имени вместо UUID в модалке редактирования оборудования
- Дедупликация при импорте оборудования объектов (проверка по обоим уникальным ключам)
- Оптимизация импорта оборудования (предзагрузка справочников)
- Исправлена логика глобальной статистики визитов (не зависит от фильтра по статусам)
- Исправлена логика дашборда: импорт создаёт один визит на заявку
