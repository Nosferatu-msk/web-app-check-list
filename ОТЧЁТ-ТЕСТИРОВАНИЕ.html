2. Найденные баги

🔴 BUG-01: 502 Bad Gateway на 8+ эндпоинтах CRITICAL
Симптом: Nginx возвращает 502 — бэкенд падает при обработке запросов.
Затронуты: уведомления, заявки, предложения, удаление из избранного, объекты профиля.
Вероятная причина: Необработанное исключение в route handler (crash процесса).
Действие: Проверить docker logs server, найти stack trace.
🔴 BUG-02: Refresh token всегда 401 CRITICAL
Эндпоинт: POST /api/auth/refresh
Симптом: Сразу после логина refresh token отклоняется.
Влияние: Через 15 мин (TTL access token) пользователь разлогинен. PWA не может обновить сессию.
🟠 BUG-03: Избранное — нет защиты от дубликатов
Эндпоинт: POST /api/profile/favorites
Симптом: Повторный запрос создаёт дубль (200 вместо 409). Нет UNIQUE constraint.
🟠 BUG-04: Условная обязательность не валидируется на сервере
Симптом: conclusion='issues' + пустые recommendations → сервер принимает (200).
Влияние: Валидация только на клиенте. API позволяет сохранить задачу с замечаниями без рекомендаций.
🔵 BUG-05: Рассинхронизация theme_color в PWA
index.html и manifest.json: #1677ff (старый синий). vite.config.ts: #0F766E (trust teal). Цвет темы в адресной строке не совпадает с UI.
