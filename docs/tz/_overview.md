# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## на разработку web-приложения «Цифровой чек-лист инженера по техническому обслуживанию оборудования»

---

## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Наименование системы
Web-приложение «Цифровой чек-лист инженера по техническому обслуживанию оборудования» (далее — Приложение).

### 1.2. Назначение системы
Автоматизация деятельности инженера по техническому обслуживанию оборудования: создание чек-листа работ, фиксация контролируемых параметров, фотофиксация состояния оборудования «до» и «после» работ, формирование отчета в формате PDF с маркированными фотографиями и отправка заказчику по email.

### 1.3. Цели проекта
- Оцифровать процесс обслуживания оборудования
- Подтвердить факт выполнения работ фотофиксацией
- Сократить трудозатраты инженера на 30–40%
- Исключить влияние человеческого фактора на полноту отчетов
- Обеспечить работу в условиях отсутствия интернета (подвалы, серверные)
- Не мешать посетителям объекта во время работ

### 1.4. Нормативные ссылки
- ФЗ-152 «О персональных данных»
- ГОСТ Р ИСО/МЭК 12207-2010 «Программная инженерия. Процессы жизненного цикла программных средств»
- СП 60.13330.2020 «Отопление, вентиляция и кондиционирование воздуха»
- ПУЭ (Правила устройства электроустановок)

## 2. ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ

| Термин | Определение |
|--------|-------------|
| **Визит** | Совокупность работ, выполняемых инженером на одном объекте за одну смену |
| **Задача** | Единица обслуживания одной единицы оборудования в рамках визита |
| **Чек-лист** | Список задач на Странице 1 визита |
| **Фото ДО** | Фотография оборудования до начала работ |
| **Фото ПОСЛЕ** | Фотография оборудования после выполнения работ |
| **Сезон** | Период эксплуатации: «Лето» (01.04–31.10) или «Зима» (01.11–31.03) |
| **PWA** | Progressive Web App — технология для работы web-приложения офлайн |
| **152-ФЗ** | Федеральный закон «О персональных данных» |
| **СС** | Сплит-система |
| **МСС** | Мультисплит-система |
| **VRV** | Variable Refrigerant Volume — мультизональная система кондиционирования |
| **РЩ/ГРЩ** | Распределительный щит / Главный распределительный щит |
| **ХВС/ГВС** | Холодное / Горячее водоснабжение |
| **ТМ (Территориальный менеджер)** | Диспетчер/контролёр региона, управляющий визитами закреплённых инженеров |

## 3. РОЛЕВАЯ МОДЕЛЬ

### 3.1. Роли пользователей

| Роль | Интерфейс | Функции |
|------|-----------|---------|
| **Инженер** | Мобильное PWA (смартфон/планшет) | Создание визита, ведение чек-листа, заполнение параметров, фотофиксация, формирование и отправка отчета |
| **ТМ** | Web-интерфейс (десктоп/планшет) | Планирование работ, контроль визитов своих инженеров, переназначение, формирование и отправка отчётов, дашборд мониторинга |
| **Администратор** | Web-интерфейс (десктоп) | Ведение справочников: адреса, виды оборудования, типовые рекомендации, типы помещений, пользователи, email заказчиков |
| **Заказчик** | Email-клиент | Получение готового отчета в виде ZIP-архива (PDF + фотографии + Excel-таблица) |

| 50 | При отклонении `room_change` proposal `roomTypeCode` откатывается к предыдущему значению | Тест API reject + проверка object_equipment |

### 10.2. Нефункциональные критерии

| № | Критерий | Метод проверки |
|---|----------|----------------|
| 1 | Время загрузки страницы ≤ 3 сек | Нагрузочное тестирование |
| 2 | Время формирования PDF ≤ 10 сек | Тест производительности |
| 3 | Поддержка 500 одновременных пользователей | Стресс-тест |
| 4 | Соответствие 152-ФЗ | Аудит безопасности |
| 5 | Работа на iOS 14+ и Android 10+ | Кросс-браузерное тестирование |

### 10.3. Критерии приемки по UX

- Инженер с опытом работы может освоить приложение за 15 минут
- Время обслуживания 1 единицы оборудования сокращено на 30–40%
- Приложение не требует обучения для базовых операциям
