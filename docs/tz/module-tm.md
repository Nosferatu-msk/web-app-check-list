### 4.3. Модуль «Территориальный менеджер (ТМ)»

**US-TM-1 — Просмотр визитов своих инженеров**
*Как* ТМ, *я хочу* видеть все визиты закреплённых за мной инженеров, *чтобы* контролировать ход выполнения работ.
Список визитов отображается с пагинацией (20 визитов на странице) с навигацией по страницам и отображением «1–20 из N». При изменении фильтров страница сбрасывается на первую.
Доступные фильтры: поиск по адресу или коду объекта (с debounce 400ms), мульти-выбор статусов, фильтр по инженеру.
Свитчер «Активные/Удалённые» доступен только администратору.

**US-TM-2 — Дашборд мониторинга**
*Как* ТМ, *я хочу* видеть сводную статистику (запланированные, в работе, завершённые, отправленные), *чтобы* оценивать загрузку и статус работ.
Статистика рассчитывается по **всем** визитам (без учёта пагинации), чтобы цифры отражали реальную картину по всем закреплённым инженерам.

**US-TM-3 — Фильтрация визитов по инженеру**
*Как* ТМ, *я хочу* фильтровать визиты по конкретному инженеру, *чтобы* быстро находить нужные данные.

**US-TM-4 — Переназначение визита**
*Как* ТМ, *я хочу* переназначить незавершённый визит с одного инженера на другого из своей группы, *чтобы* обеспечить выполнение работ при замене.

**US-TM-5 — Редактирование визита инженера**
*Как* ТМ, *я хочу* редактировать данные визита перед отправкой, *чтобы* скорректировать отчёт.

**US-TM-6 — Формирование и отправка отчёта**
*Как* ТМ, *я хочу* формировать и отправлять отчёт по визиту своего инженера, *чтобы* обеспечить резервирование процесса отправки.

**US-TM-7 — Удаление визита**
*Как* ТМ, *я хочу* удалять визиты своих инженеров (soft delete), *чтобы* исключать некорректные данные из отчётности.

**US-TM-8 — Формирование сводного отчёта за период**
*Как* ТМ, *я хочу* формировать сводный отчёт по всем визитам за указанный период (дата начала — дата окончания), *чтобы* предоставлять руководству агрегированную информацию о выполненных работах.
Отчёт имеет единую структуру: титульный лист (название, период, дата формирования, ФИО сформировавшего), группировка по объектам (каждый с новой страницы), визиты с задачами, параметры, превью фотографий (width ≤ 400px), заключения, рекомендации. Формат — PDF.

**US-TM-9 — Формирование отчёта по объектам**
*Как* ТМ, *я хочу* выбирать один или несколько объектов и формировать отчёт за выбранный период, *чтобы* консолидировать данные по группе зданий.
Отчёт имеет идентичную структуру с отчётом за период (US-TM-8). Поддерживается мультивыбор объектов через чек-боксы. Период обязателен.

**US-TM-12 — Превью фотографий в сводном отчёте**
*Как* ТМ, *я хочу*, чтобы в сводном PDF-отчёте были встроены визуальные превью фотографий, *чтобы* оценивать качество работ без открытия ZIP-архива.
Фотографии масштабируются через `sharp` до width ≤ 400px и встраиваются в PDF как base64. При превышении 200 фото — автоматическое переключение в упрощённый режим (текстовые метки + отдельный ZIP).

**US-TM-13 — Загрузка сканов подписанных актов**
*Как* ТМ, *я хочу* прикреплять сканы подписанных актов (JPG/PNG/PDF, до 10 файлов, до 50 МБ) при формировании сводного отчёта, *чтобы* они автоматически включались в итоговый PDF.
Изображения автоматически сжимаются на сервере (width ≤ 1200px, JPEG quality 80%, EXIF удалён). PDF-файлы объединяются через `pdf-lib`. Загрузка необязательна.

**US-TM-10 — Закреплённые объекты в профиле ТМ**
*Как* ТМ, *я хочу* видеть в своём профиле список закреплённых за мной объектов (адресов), *чтобы* быстро переходить к созданию визитов на этих объектах.
Для каждого объекта отображается адрес, аналитический код и индикатор наличия неисправностей из последнего визита. Клик по объекту открывает форму создания визита.
Список содержит пагинацию (по умолчанию 10 объектов на странице, выбор 10/20/50) с отображением «1–10 из N» и счётчиком общего количества объектов в заголовке карточки.

**US-TM-11 — Создание инженера с привязкой к ТМ**
*Как* ТМ, *я хочу* создавать учётные записи инженеров прямо из своего профиля с автоматической привязкой ко мне, *чтобы* быстро пополнять команду без обращения к администратору.
При создании указываются ФИО, email и специализация. Инженер получает временный пароль `Welcome2026!` на email с инструкцией сменить пароль при первом входе.

**US-TM-14 — Аналитика визитов (верификация фото)**
*Как* ТМ, *я хочу* видеть визиты своих инженеров с отклонениями по результатам автоматических проверок фото, *чтобы* выявлять некорректную фотофиксацию и запрашивать пересъёмку.
Страница «Аналитика» доступна в нижней навигации. ТМ видит только визиты своих инженеров (через `tm_engineers`). Функционал аналогичен US-ADM-14: KPI-карточки, фильтры, список визитов, детали с чекбоксами, действия «Запросить пересъёмку» и «Подтвердить визит». При запросе пересъёмки — выбранные фото удаляются, статус визита и связанных заявок обновляется. См. раздел 22 Спецификации.

**US-TM-15 — Команды ТМ (группировка территориальных менеджеров)**
*Как* лидер ТМ, *я хочу* объединять нескольких ТМ в команду и видеть визиты, заявки, отчёты и аналитику всех инженеров своей команды (включая инженеров других ТМ), *чтобы* координировать работу территории и иметь единую картину обслуживания.
Администратор создаёт команду, назначая лидера (ТМ) и добавляя участников (других ТМ). Лидер видит визиты, заявки и отчёты всех инженеров, закреплённых за любым ТМ команды. Участник команды (ТМ2) видит инженеров лидера (обратная связь). Управление командами осуществляется на вкладке «Команды» страницы «Привязки ТМ» в админке.

**US-TM-16 — Создание визита с выбором инженера из списка**
*Как* ТМ, *я хочу* выбирать инженера из выпадающего списка при создании визита, *чтобы* избежать ошибок ввода и гарантировать корректную привязку визита к инженеру.
Поле «Инженер» при создании визита отображается как `<Select>` с списком инженеров из привязок ТМ (включая команду). Первая опция: «Без инженера (визит под собой)» — визит создаётся с `userId` самого ТМ. При выборе инженера визит создаётся с `userId` инженера и статусом `planned`. `contractId` подставляется автоматически из `tm_objects` по адресу.

### 4.4. Модуль «Заказчик»

**US-ZAK-1 — Получение отчета**
*Как* заказчик, *я хочу* получать email с ZIP-архивом (PDF + маркированные фото + Excel-таблица оборудования), *чтобы* иметь доказательную базу выполненных работ.
