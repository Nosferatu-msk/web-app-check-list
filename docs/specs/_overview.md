# СПЕЦИФИКАЦИЯ НА РАЗРАБОТКУ
## Web-приложение «Цифровой чек-лист инженера по техническому обслуживанию оборудования»

**Версия:** 18.0
**Дата:** 17.09.2026
**Статус:** Готов к разработке

---

## 1. ОБЗОР ПРОЕКТА

### 1.1. Наименование
Web-приложение «Цифровой чек-лист инженера по техническому обслуживанию оборудования» (далее — Приложение).

### 1.2. Назначение
Автоматизация деятельности инженера по техническому обслуживанию оборудования:
- Создание чек-листа работ на объекте
- Фиксация контролируемых параметров оборудования
- Фотофиксация состояния оборудования «до» и «после»
- Формирование PDF-отчёта с маркированными фотографиями
- Отправка отчёта заказчику по email

### 1.3. Ключевые ограничения
- **Офлайн-работа** — обязательна (подвалы, серверные, тепловые узлы без связи)
- **Мобильный интерфейс** — основной сценарий инженера (смартфон/планшет)
- **Соответствие 152-ФЗ** — предупреждения о персональных данных при фотофиксации
- **Все тексты интерфейса** — на русском языке

### 2.2. Технологический стек

| Слой | Технология | Обоснование |
|------|-----------|-------------|
| Frontend | **React 18+ / TypeScript** | Экосистема PWA, компонентный подход |
| State Management | **Zustand** | Лёгкость, поддержка TypeScript |
| UI-библиотека | **Ant Design Mobile / Vant** | Готовые мобильные компоненты |
| Service Worker | **Workbox** | Упрощение офлайн-кеширования |
| Локальное хранилище | **IndexedDB (Dexie.js)** | Структурированное офлайн-хранилище |
| Backend | **Node.js + Express** | Быстрая разработка, REST API |
| ORM | **Prisma** | Миграции, типобезопасность |
| База данных | **PostgreSQL 15+** | Надёжность, JSONB-поддержка |
| Генерация PDF | **Puppeteer** (сервер) | Рендеринг HTML → PDF |
| Генерация ZIP | **JSZip** (клиент) | Без серверной зависимости |
| Email | **Nodemailer** | SMTP/SMTPS, Ethereal для тестов |
| Аутентификация | **JWT** (access + refresh) | Stateless, подходит для PWA |
| Валидация | **Zod** | Типобезопасная валидация |
| Offline storage | **Dexie.js (IndexedDB)** | Локальное хранение визитов, задач, фото |
| Service Worker | **Workbox (vite-plugin-pwa)** | Кэширование API, NetworkFirst стратегия |
| CSV parsing | **csv-parser, iconv-lite** | Парсинг CSV с автоопределением разделителя |
| Rate Limiting | **express-rate-limit** | Защита auth-эндпоинтов от brute-force |
| Сборка | **Vite** | Быстрая dev/prod сборка |
