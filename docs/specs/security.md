## 8. БЕЗОПАСНОСТЬ

### 8.1. Аутентификация и авторизация

- **JWT-токены:** access (15 мин) + refresh (7 дней)
- **Роли:** `engineer`, `tm`, `admin`
- **Middleware проверки прав** на каждом защищённом маршруте
- Инженер видит только свои визиты
- ТМ видит визиты только своих инженеров (через таблицу tm_engineers)
- Администратор имеет доступ ко всем справочникам и визитам

**Матрица доступа:**

| Функция | Инженер | ТМ | Администратор | Заказчик |
|---------|:-------:|:--:|:-------------:|:--------:|
| Создание визита | ✅ | ✅ (назначение на инженера) | ❌ | ❌ |
| Заполнение параметров | ✅ | ❌ | ❌ | ❌ |
| Фотофиксация | ✅ | ❌ | ❌ | ❌ |
| Формирование отчета | ✅ | ✅ (визиты своих инженеров) | ❌ | ❌ |
| Отправка отчета по email | ✅ | ✅ (статус sent_by_tm) | ❌ | ❌ |

### 8.2. Защита данных

- Пароли: **bcrypt** (12 раундов)
- Передача данных: **TLS 1.3** (HTTPS)
- Валидация входных данных: **Zod / Pydantic** на сервере
- Защита от XSS: экранирование вывода, CSP-заголовки
- Защита от CSRF: SameSite cookies + CSRF-токены
- Защита от SQL-инъекций: параметризованные запросы (ORM)

### 8.3. Соответствие 152-ФЗ

- Предупреждение при фотофиксации в клиентских зонах
- Персональные данные не хранятся в фото (только предупреждение)
- Email заказчиков хранятся с минимальными необходимыми данными

## 10. СОВМЕСТИМОСТЬ

| Параметр | Требования |
|----------|------------|
| Браузеры | Chrome 90+, Safari 14+, Firefox 88+, Edge 90+, Samsung Internet 14+ |
| Устройства | Смартфоны (iOS 14+, Android 10+), планшеты (iPad, Android) |
| Разрешение | 320×568 — 1920×1080+ |
| PWA | Установка на домашний экран, иконка, splash-screen |
| PWA-иконки | `icon-192.png` (192×192), `icon-512.png` (512×512) — сгенерированы и включены в проект |
| PWA Viewport | `viewport-fit=cover` для Safe Area на iPhone |
| Адаптивность | Mobile-first, breakpoints привязаны к Ant Design Grid (см. раздел 16) |
| Safe Area | `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` для фиксированных элементов |
| Touch targets | Минимальный размер кликабельных элементов — 40×40 px на мобильных (controlHeight: 40 через ConfigProvider) |
