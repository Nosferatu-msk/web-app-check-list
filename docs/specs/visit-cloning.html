🖥️ Макет 1: Страница визита — десктоп (вариант A: dropdown ⋮)

Кнопка «Клонировать» размещается в dropdown-меню (⋮) в шапке визита. Единый паттерн для десктопа и мобильного. Нет риска случайного нажатия.

📋 Задачи реализации

Сервер (3 задачи, ~3 часа)

  • 1
    POST /api/visits/:id/clone — эндпоинт клонирования
    Проверки, транзакция, копирование задач, автопривязка заявок, AuditLog 2ч
  • 2
    Вынести функцию автопривязки заявок — из visits.ts в отдельный модуль
    autoAssignISZHRequests() + autoAssignBySerialNumber() — переиспользовать в clone 0.5ч
  • 3
    Функция determineSeason() — вынести в utils
    Определение сезона по дате (апрель–сентябрь = лето) 0.5ч

Клиент (4 задачи, ~2.5 часа)

  • 4
    API-метод cloneVisit() — client/src/api/client.ts
    POST /api/visits/:id/clone, обработка ошибок 409/423 0.25ч
  • 5
    Кнопка + модалка в VisitPage.tsx
    Кнопка «Клонировать» (десктоп: в ряду действий, мобильный: под «Сохранить»), модальное окно подтверждения 1ч
  • 6
    Кнопка в VisitListPage.tsx
    Десктоп: иконочная кнопка (size=small). Мобильный: пункт в dropdown actionItems 0.75ч
  • 7
    Условная видимость кнопки
    Показывать только для completed/sent/sent_by_engineer/sent_by_tm/corrected_by_tm. Проверка офлайн → disabled. 0.5ч

Тестирование (1 задача, ~0.5 часа)

  • 8
    E2E-тесты клонирования
    Кнопка видна/скрыта, модалка, клонирование, проверка задач, офлайн 0.5ч
Итого: ~6 часов (сервер 3ч + клиент 2.5ч + тесты 0.5ч)
