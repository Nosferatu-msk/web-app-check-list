## 16. АДАПТИВНАЯ ВЕРСТКА И МОБИЛЬНАЯ ОПТИМИЗАЦИЯ

> Раздел добавлен в соответствии с ТЗ «Адаптивная верстка и оптимизация UI/UX» v2.0 от 25.07.2026.

### 16.1. Система breakpoints

Breakpoints привязаны к Ant Design Grid для согласованности с компонентами библиотеки:

| Тип устройства | Ant Design token | Ширина экрана | Интерфейс | Навигация |
|---|---|---|---|---|
| Смартфон | `xs` / `sm` | < 768 px | Карточный вид, одноколоночная верстка | Bottom Navigation |
| Планшет | `md` | 768–991 px | Гибридный вид, двухколоночная верстка | Sidebar |
| ПК | `lg` / `xl` | ≥ 992 px | Таблицы, многоколоночные дашборды | Sidebar |

Определение устройства:
```typescript
const { md } = Grid.useBreakpoint();
const isMobile = !md; // < 768px
```

### 16.2. PWA-адаптация

- **Viewport meta:** `viewport-fit=cover` для поддержки Safe Area на iPhone
- **Manifest:** `display: standalone`, `orientation: portrait`, `theme_color: #1677ff`
- **Service Worker:** CSS кэшируется через Workbox precaching; при обновлении — автоматическая инвалидация через build hash
- **Safe Area CSS:** `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` для Header и Bottom Navigation

### 16.3. Адаптация интерфейса Инженера

#### 16.3.1. VisitPage — чек-лист задач (мобильный)

Таблица «Проведённые работы» трансформируется в **список карточек** с группировкой по комнатам:

```text
┌─────────────────────────────────────────────┐
│ 📍 Серверная                                │
│ ┌─────────────────────────────────────────┐ │
│ │ Внутр. блок СС          📷 2/2   ✅  ⋮ │ │
│ │ Серверная · Daikin FTXS35K              │ │
│ └─────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────┐ │
│ │ ⚡ РЩ/ГРЩ               📷 1/1   🔄  ⋮ │ │
│ │ Электрощитовая · ABB GS420              │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

- **Статусы:** пиктограммы + сокращённый текст для accessibility (aria-label)
- **Действия:** кнопка ⋮ (overflow menu) — основной паттерн на всех платформах; свайп — опционально, только Android
- **Тап по карточке** → переход на TaskPage

#### 16.3.2. TaskPage — адаптация формы параметров

- **Секции (Accordion):** поля группируются в сворачиваемые блоки («Основные параметры», «Параметры сети», «Состояние», «Проведённые работы», «Рекомендации»)
- **Label:** сокращение длинных названий на мобильных, полный текст — в tooltip
- **Нативные пикеры:** `antd-mobile` `Picker` (Bottom Sheet) вместо `<Select>` на мобильных
- **Таблица «Проведённые работы»** → список карточек на мобильных

#### 16.3.3. GroupTaskPage — групповая задача (мобильный)

- **Tabs (вкладки)** для переключения между единицами оборудования вместо таблицы
- Общие параметры — вверху страницы, вне вкладок
- Переключение — свайпом или тапом

#### 16.3.4. PhotoPage — фотофиксация

- Кнопки «Сделать фото» и «Выбрать файл» — на всю ширину, вертикально
- Сетка превью: 2×2 или 1×2 (адаптивно)
- **iOS PWA fallback:** `capture="environment"` не поддерживается в standalone → диалог выбора камера/галерея

#### 16.3.5. Bottom Navigation

Нижняя панель навигации для инженера на мобильных (< 768px):

| Вкладка | Иконка | Маршрут | Badge |
|---|---|---|---|
| Визиты | `UnorderedListOutlined` | `/` | — |
| Заявки | `FormOutlined` | `/my-requests` | Счётчик новых |
| Отчёты | `BarChartOutlined` | `/reports/summary` | — |
| Профиль | `UserOutlined` | `/profile` | — |

- Высота: 56px + `env(safe-area-inset-bottom)`
- При фокусе на input — панель скрывается (`visualViewport` API + iOS `resize` fallback)
- Реализация: кастомный `<BottomNav>` или `antd-mobile` `TabBar`

### 16.4. Адаптация интерфейса ТМ

- **Дашборд (≥ 768px):** таблица с фильтрами в шапке
- **Смартфон (< 768px):** карточки; фильтры — в Drawer (иконка воронки); сортировка — иконка ⇅
- **Назначение инженера:** full-screen modal с поиском и чек-боксами
- **Специализации:** цветные бейджи (ВиК — синий, ИСЖ — зелёный, ГПМ — оранжевый, ДГУ — фиолетовый, ИБП — красный)

### 16.5. Адаптация интерфейса Администратора

- **Таблицы справочников (< 768px):** трансформация в аккордеоны/карточки
- **Массовый импорт:** на мобильных — только кнопка «Выбрать файл» (DnD скрыт)
- Существующая адаптация админ-панели сохраняется (Drawer, мобильный header, горизонтальный скролл таблиц)

### 16.6. Технические требования

- **Типографика:** масштабирование через Ant Design ConfigProvider токены (не CSS `clamp()`)
- **Touch Targets:** минимум 44×44 px
- **Отступы:** padding карточек на мобильных — 16px (вместо 24px)
- **Клавиатура:** `inputmode="decimal"` для числовых полей, `inputmode="numeric"` для кодов
- **Производительность:** `antd-mobile` — lazy import; lazy loading изображений
- **Accessibility:** `aria-label` на иконках-статусах, focus trap в модалках, контрастность ≥ 4.5:1, keyboard navigation

### 16.7. Критерии приемки

1. Отсутствие горизонтальной прокрутки на экране 375px
2. Таблица задач VisitPage → карточки с группировкой по комнатам на мобильных
3. Все статусы — пиктограммы + aria-label
4. Touch targets ≥ 44×44 px
5. Safe Area на iPhone 11-17 не перекрывает контент
6. Keyboard handling: Bottom Nav скрывается при фокусе на input
7. PWA офлайн-режим работает после обновления стилей
8. `antd-mobile` lazy import не увеличивает initial bundle более чем на 50 КБ (gzipped)
