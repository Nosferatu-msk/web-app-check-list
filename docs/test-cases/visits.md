## TC-004: Создание визита — обязательные поля

**Предусловие:** Инженер авторизован.
**Шаги:**
1. Нажать «Новый визит»
2. Не заполнять никакие поля, нажать «Сохранить»

**Ожидаемый результат:** Формы валидации показывают ошибки на обязательных полях (Инженер, Адрес, Дата, Время). Визит не создан.
**Приоритет:** Критический

---

## TC-005: Создание визита — автозаполнение

**Предусловие:** Инженер авторизован.
**Шаги:**
1. Нажать «Новый визит»

**Ожидаемый результат:**
- Поле «Дата» заполнено текущей датой
- Поле «Время» заполнено текущим временем
- Поле «Сезон» автоматически определено (Лето: апрель–октябрь, Зима: ноябрь–март)

**Приоритет:** Высокий

---

## TC-006: Создание визита — выбор адреса из справочника

**Шаги:**
1. В поле «Адрес» начать ввод «Тверская»
2. Выбрать адрес из выпадающего списка
3. Заполнить остальные обязательные поля
4. Нажать «Сохранить»

**Ожидаемый результат:** Визит создан, выполнен переход на страницу визита с сохранённым адресом.
**Приоритет:** Критический

## TC-007: Добавление задачи — модальное окно с тремя вкладками

**Предусловие:** Визит создан и сохранён.
**Шаги:**
1. Нажать «+ Добавить оборудование»
2. Проверить структуру модального окна

**Ожидаемый результат:** Модальное окно содержит 3 вкладки:
- «📍 Уровень помещения» — список помещений с количеством единиц оборудования
- «🏠 Уровень объекта» — список оборудования без привязки к помещению
- «➕ Добавить новое» — ручной ввод оборудования

**Приоритет:** Критический

## TC-008: Добавление задачи — вкладка «Добавить новое», с типом помещения

**Шаги:**
1. Нажать «+ Добавить оборудование»
2. Переключиться на вкладку «Добавить новое»
3. Выбрать вид оборудования
4. Выбрать тип помещения «Серверная»
5. Нажать «Добавить»

**Ожидаемый результат:** Задача добавлена в чек-лист со статусом «Не начато».
**Приоритет:** Критический

## TC-009: Удаление задачи — кнопка работает корректно

**Предусловие:** В визите есть 2+ задачи.
**Шаги:**
1. В перечне задач нажать кнопку «Удалить» (корзина) на одной из задач
2. Подтвердить удаление

**Ожидаемый результат:** Задача удалена из списка. Перехода к редактированию задачи НЕ произошло. Нумерация оставшихся задач пересчитана.
**Приоритет:** Критический

## TC-010: Заполнение параметров — значения по умолчанию

**Предусловие:** Задача создана (тип «РЩ/ГРЩ», помещение «Серверная»).
**Шаги:**
1. Кликнуть на задачу в чек-листе

**Ожидаемый результат:** Страница параметров открыта. Все поля заполнены значениями по умолчанию:
- «Состояние контактных соединений» = «Удовлетворительно»
- «Исправность всех запирающих устройств» = «Да»
- «Заключение» = «Исправно, замечаний нет»

**Приоритет:** Критический

## TC-011: Заполнение параметров — обязательные поля

**Предусловие:** Задача «Прибор учёта э/э».
**Шаги:**
1. Открыть задачу
2. Очистить поле «Модель счётчика»
3. Нажать «Сохранить и вернуться в чек-лист»

**Ожидаемый результат:** Валидация показывает ошибку «Заполните поле» на обязательных полях. Сохранение НЕ выполнено. Задача остаётся в статусе «В работе» или «Не начато».
**Приоритет:** Критический

## TC-012: Статус задачи — сохранение без фото

**Предусловие:** Задача создана, все обязательные поля заполнены.
**Шаги:**
1. Открыть задачу, заполнить все параметры
2. Нажать «Сохранить и вернуться в чек-лист» (НЕ загружая фото)

**Ожидаемый результат:** В чек-листе задача в статусе **«В работе»** (не «Выполнено», т.к. фото не загружены).
**Приоритет:** Критический

## TC-017: Дубликаты фото — запрет загрузки одного файла

**Предусловие:** Задача «Внутренний блок СС» (2 фото).
**Шаги:**
1. Загрузить файл `photo.jpg` как «Фото ДО»
2. Попытаться загрузить тот же файл `photo.jpg` как «Фото ПОСЛЕ»

**Ожидаемый результат:** Предупреждение «Этот файл уже загружен. Используйте другое фото.» Фото ПОСЛЕ НЕ загружено. Клиент вычисляет SHA-256 хеш сжатого файла и сравнивает с последним загруженным.
**Приоритет:** Высокий

## TC-018: Фотофиксация — кнопка удаления не перекрывает подписи

**Предусловие:** Фото загружено.
**Шаги:**
1. Перейти к фотофиксации

**Ожидаемый результат:**
- Подписи «📷 Фото ДО выполнения работ» и «📷 Фото ПОСЛЕ выполнения работ» видны и не перекрыты
- Кнопка удаления (корзина) расположена на изображении, имеет полупрозрачный фон
- Клик по кнопке удаления не вызывает переход к редактированию задачи

**Приоритет:** Средний

- Ошибка: «Задача №N (ИБП): не заполнена ёмкость батарей»
- HTTP 422, `missingFields: ["battery_capacity"]`
- Визит НЕ завершён
**Приоритет:** Критический

### TC-VAL-017: Завершение визита с задачами в статусе not_started

**Предусловие:** Визит содержит 3 задачи: 2 в статусе `completed`, 1 в статусе `not_started`.
**Шаги:**
1. Нажать «Завершить визит»

**Ожидаемый результат:**
- Ошибка: «Задача №N не завершена (статус: Не начато)»
- Визит НЕ завершён
- Кнопка «Завершить визит» неактивна (disabled) на клиенте
**Приоритет:** Критический

### TC-VAL-018: Завершение визита со всеми заполненными обязательными полями

**Предусловие:** Визит содержит задачи: «Прибор учёта э/э» (readings заполнены), «Внутренний блок СС» (room_temperature заполнена), «РЩ/ГРЩ» (все параметры заполнены). Все задачи в статусе `completed`.
**Шаги:**
1. Нажать «Завершить визит»

**Ожидаемый результат:**
- Визит успешно завершён (HTTP 200)
- Статус визита → `completed`
- `time_end` заполнен автоматически
- Переход на страницу отчёта
**Приоритет:** Критический
