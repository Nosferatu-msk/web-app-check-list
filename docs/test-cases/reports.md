## TC-028: Скачивание ZIP-архива

**Предусловие:** Отчёт сформирован.
**Шаги:**
1. Нажать «Скачать ZIP-архив»

**Ожидаемый результат:**
- Скачан файл `OTCHET_{street}_{house}_{date}.zip`
- Структура архива:
  ```
  OTCHET_*.zip
  ├── OTCHET_*.pdf
  ├── OTCHET_*.xlsx
  └── Photos/
      ├── 01_splitvn_server_before.jpg
      ├── 01_splitvn_server_after.jpg
      └── ...
  ```
- PDF содержит все секции по задачам с фотографиями
- Имена фото соответствуют шаблону `{№}_{equipment}_{room}_{moment}.jpg`
- Excel-файл (`.xlsx`) содержит таблицу оборудования с колонками: Код объекта, Вид оборудования, Серийный номер, Изготовитель, Модель, Показания
- Количество строк в Excel соответствует количеству задач (для групповых задач — количеству единиц оборудования)

**Приоритет:** Критический

## TC-170: Сводный отчёт — единая структура

**Предусловие:** ТМ авторизован. Есть завершённые визиты за последний месяц.
**Шаги:**
1. Открыть «Сводные отчёты»
2. Выбрать тип «Отчёт за период», указать диапазон дат
3. Нажать «Сформировать и скачать PDF»
4. Открыть PDF
5. Повторить для типа «Отчёт по объектам», выбрав 2 объекта

**Ожидаемый результат:**
- Оба отчёта имеют идентичную структуру: титульный лист → статистика → разделы по объектам → визиты → задачи
- Титульный лист содержит: название, период, дату формирования, ФИО сформировавшего
- Каждый объект начинается с новой страницы
**Приоритет:** Критический
