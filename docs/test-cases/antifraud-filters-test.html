🧪 Тестирование антифрод — фильтры и массовое подтверждение

✅ Готово к тестированию

Коммит: 16e7815

Дата: 21.10.2026

Что реализовано:

  • Фильтр по критичности на десктопе (сегментный контрол)
  • Массовое подтверждение предупреждений (кнопка + модальное окно)

📋 Тест-кейс 1: Фильтр по критичности (десктоп)

Шаги:

  1. Открыть страницу аналитики на десктопе
  2. Найти сегментный контрол в блоке фильтров
  3. Нажать кнопку «Критические»
  4. Проверить, что показываются только визиты с критическими отклонениями
  5. Нажать кнопку «Предупреждения»
  6. Проверить, что показываются только визиты с предупреждениями без критических
  7. Нажать кнопку «Все»
  8. Проверить, что показываются все визиты с отклонениями
✅ Ожидаемый результат:
Фильтр работает корректно, пагинация сбрасывается на страницу 1 при переключении фильтра.

📋 Тест-кейс 2: Массовое подтверждение предупреждений

Шаги:

  1. Открыть страницу аналитики
  2. Нажать кнопку «Предупреждения» в сегментном контроле
  3. Убедиться, что есть визиты с предупреждениями (без критических)
  4. Найти кнопку «Подтвердить все предупреждения (N)» в шапке страницы
  5. Нажать на кнопку
  6. Проверить, что открылось модальное окно со статистикой
  7. Проверить данные в модальном окне:
    • Визитов: N
    • Отклонений: M
    • Критические: 0 (не будут затронуты)
  8. Нажать кнопку «Подтвердить»
  9. Проверить, что все предупреждения подтверждены
  10. Проверить, что критические отклонения не затронуты
✅ Ожидаемый результат:
Все предупреждения подтверждены, критические не затронуты. Появляется сообщение об успехе.

📋 Тест-кейс 3: Кнопка не показывается

Шаги:

  1. Открыть страницу аналитики
  2. Нажать кнопку «Критические» в сегментном контроле
  3. Проверить, что кнопка «Подтвердить все предупреждения» НЕ показывается
  4. Нажать кнопку «Все»
  5. Проверить, что кнопка «Подтвердить все предупреждения» НЕ показывается
✅ Ожидаемый результат:
Кнопка скрыта, если фильтр не равен warning или если нет визитов с предупреждениями.

📋 Тест-кейс 4: Мобильная версия

Шаги:

  1. Открыть страницу аналитики на мобильном устройстве
  2. Проверить, что табы «Все | Критические | Предупреждения» работают
  3. Проверить, что кнопка массового подтверждения НЕ показывается на мобильном
✅ Ожидаемый результат:
Мобильная версия работает корректно, табы переключаются, кнопка массового подтверждения скрыта (реализована только для десктопа).

📊 Критерии приемки

  • ☐ Фильтр по критичности работает на десктопе
  • ☐ Фильтр консистентен с мобильным интерфейсом
  • ☐ Кнопка массового подтверждения показывается только при фильтре "Предупреждения"
  • ☐ Модальное окно показывает корректную статистику
  • ☐ Массовое подтверждение обрабатывает только предупреждения (не критические)
  • ☐ Действие записывается в audit_log
  • ☐ UI соответствует дизайн-системе (trust teal, Ant Design токены)
  • ☐ Мобильная адаптация работает корректно
⚠️ Важно: Перед тестированием убедитесь, что на production есть визиты с предупреждениями для тестирования. Если таких визитов нет, создайте тестовые данные.
