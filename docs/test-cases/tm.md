## TC-036.2: ТМ — создание визита с выбором инженера (Select)

**Предусловие:** ТМ имеет привязанных инженеров (tm_engineers).
**Шаги:**
1. Войти как ТМ
2. Нажать «Создать визит»
3. В поле «Инженер» открыть выпадающий список

**Ожидаемый результат:**
- Отображается `<Select>` с списком инженеров из привязок ТМ (включая команду tm_team_member)
- Первая опция: «Без инженера (визит под собой)»
- При выборе инженера — визит создаётся с `userId` инженера, ТМ видит его в списке
- При выборе «Без инженера» — визит создаётся с `userId` ТМ, ТМ видит его
- `contractId` подставляется автоматически из `tm_objects` по адресу

**Приоритет:** Высокий

## TC-166: ТМ — пагинация закреплённых объектов

**Предусловие:** ТМ авторизован. За ним закреплено более 10 объектов.
**Шаги:**
1. Открыть профиль ТМ
2. Проверить секцию «Закреплённые объекты»
3. Убедиться, что отображается не более 10 объектов на странице
4. Проверить наличие пагинации внизу списка
5. Перейти на следующую страницу

**Ожидаемый результат:**
- В заголовке карточки отображается общее количество объектов (например, «42 объектов»)
- На первой странице отображается до 10 объектов
- Внизу списка отображается пагинация с текстом «1–10 из 42»
- При переходе на страницу 2 — отображаются объекты 11–20
- Выпадающий список позволяет выбрать 10/20/50 объектов на странице
**Приоритет:** Высокий

## TC-TEAM-001: Админ — создание команды ТМ

**Предусловие:** Администратор авторизован. В системе есть минимум 2 ТМ (ТМ-лидер и ТМ-участник).
**Шаги:**
1. Перейти в Админ → Привязки ТМ
2. Открыть вкладку «Команды»
3. Выбрать ТМ-лидера из списка
4. Добавить ТМ-участника в команду (`POST /api/admin/tm-team` с `{ memberTmId, leadTmId }`)

**Ожидаемый результат:**
- Связь создана в таблице `tm_team_members`
- ТМ-участник отображается в списке команды лидера
- API `GET /api/admin/tm-team` возвращает созданную связь

**Приоритет:** Критический

## TC-TEAM-002: Лидер ТМ — видимость визитов инженеров команды

**Предусловие:** Администратор создал команду: ТМ-лидер → ТМ-участник. У ТМ-участника есть закреплённый инженер с визитами.
**Шаги:**
1. Авторизоваться как ТМ-лидер
2. Открыть список визитов
3. Проверить наличие визитов инженера, закреплённого за ТМ-участником

**Ожидаемый результат:**
- ТМ-лидер видит визиты инженеров ТМ-участника (через `getTeamEngineerIds`)
- Визиты отображаются наравне с визитами собственных инженеров
- Фильтр по инженеру содержит инженеров ТМ-участника

**Приоритет:** Критический

## TC-TEAM-004: Команды ТМ — заявки и аналитика

**Предусловие:** Команда ТМ создана (лидер + участник). У инженеров обоих ТМ есть заявки и завершённые визиты.
**Шаги:**
1. Авторизоваться как ТМ-лидер
2. Открыть страницу заявок — проверить видимость заявок инженеров ТМ-участника
3. Открыть страницу аналитики — проверить видимость визитов с отклонениями инженеров ТМ-участника

**Ожидаемый результат:**
- ТМ-лидер видит заявки всех инженеров команды (свои + ТМ-участника)
- Аналитика содержит визиты всех инженеров команды с отклонениями по фото
- KPI-карточки учитывают данные всех инженеров команды

**Приоритет:** Высокий

## TC-TEAM-005: Удаление связи из команды ТМ

**Предусловие:** Команда ТМ создана (лидер + участник).
**Шаги:**
1. Авторизоваться как администратор
2. Перейти в Админ → Привязки ТМ → вкладка «Команды»
3. Удалить связь ТМ-участника (`DELETE /api/admin/tm-team/:id`)
4. Авторизоваться как ТМ-лидер, проверить список визитов

**Ожидаемый результат:**
- Связь удалена из `tm_team_members`
- ТМ-лидер больше не видит визиты инженеров удалённого ТМ-участника
- Визиты собственных инженеров остаются доступными

**Приоритет:** Высокий
