## TC-080: Объект-Оборудование — добавление через админку

**Предусловие:** Администратор авторизован. Адрес создан.
**Шаги:**
1. Перейти в Админ → Оборудование объектов
2. Выбрать объект (фильтр по адресу)
3. Нажать «Добавить»
4. Заполнить: тип оборудования, помещение (опционально), марка, модель, серийный номер, местоположение
5. Сохранить

**Ожидаемый результат:** Оборудование добавлено к объекту. Отображается в списке. Поле «Тип помещения» можно оставить пустым — запись будет отображаться с пометкой «⚠️ Не указано».
**Приоритет:** Высокий

## TC-081: Модальное окно — вкладка «Связанное оборудование»

**Предусловие:** К объекту привязано 5 единиц оборудования. Визит создан и сохранён.
**Шаги:**
1. Нажать «+ Добавить оборудование»
2. Проверить содержимое вкладки «Связанное оборудование»

**Ожидаемый результат:** На вкладке отображаются 5 единиц оборудования из привязки объекта (отфильтрованы по специализации инженера). Каждая позиция показывает: вид оборудования, марку/модель, серийный номер, тип помещения. Чекбоксы по умолчанию не отмечены.
**Приоритет:** Критический

## TC-082: Модальное окно — пакетное создание задач из связанного оборудования

**Предусловие:** На вкладке «Связанное оборудование» отображаются 5 позиций.
**Шаги:**
1. Отметить чекбоксами 3 единицы оборудования
2. Нажать «Добавить (3)»

**Ожидаемый результат:** Создано 3 задачи с соответствующими типами оборудования, помещениями, марками, моделями и серийными номерами. Задачи отображаются в чек-листе со статусом «Не начато». Модальное окно закрыто.
**Приоритет:** Критический

## TC-145: Группировка оборудования — вкладка «Уровень помещения»

**Предусловие:** К объекту привязаны единицы оборудования, распределённые по помещениям. Визит создан и сохранён.
**Шаги:**
1. Нажать «+ Добавить оборудование»
2. Переключиться на вкладку «📍 Уровень помещения»
3. Выбрать помещение из списка (например, «Серверная»)
4. Убедиться, что отображается список оборудования, относящегося к этому помещению
5. Нажать «Добавить (N)»

**Ожидаемый результат:** На вкладке отображается список помещений с указанием количества единиц оборудования в каждом. При выборе помещения — показывается список единиц оборудования из этого помещения, все чекбоксы отмечены по умолчанию. Кнопка «Добавить (N)» создаёт N задач в чек-листе. Модальное окно закрывается.
**Приоритет:** Критический

## TC-148: Группировка — выбрать все / снять выделение

**Предусловие:** На вкладке «📍 Уровень помещения» выбрано помещение с несколькими единицами оборудования.
**Шаги:**
1. Убедиться, что все чекбоксы отмечены по умолчанию
2. Снять выделение с одного или нескольких чекбоксов
3. Проверить значение на кнопке «Добавить (N)»
4. Снять все чекбоксы
5. Проверить состояние кнопки «Добавить»

**Ожидаемый результат:** Кнопка «Добавить (N)» показывает текущее количество отмеченных единиц и обновляется при изменении выделения. При снятии всех чекбоксов кнопка неактивна (disabled).
**Приоритет:** Высокий

## TC-150: Новые виды оборудования — все 4 подвида требуют 2 фото

**Предусловие:** Визит создан.
**Шаги:**
1. Добавить задачу типа «Тепловая завеса», заполнить параметры
2. Перейти к фотофиксации, проверить требуемое количество фото
3. Вернуться, добавить задачу типа «Приточная установка»
4. Проверить требуемое количество фото
5. Повторить для «Приточно-вытяжная установка» и «Вытяжная установка»

**Ожидаемый результат:** Все 4 подвида вентиляционных установок (Тепловая завеса, Приточная установка, Приточно-вытяжная установка, Вытяжная установка) требуют 2 фото (ДО/ПОСЛЕ). Статус «Выполнено» устанавливается только после загрузки обоих фото.
**Приоритет:** Критический

## TC-151: Автозаполнение счётчиков — модель и номер из справочника

**Предусловие:** К объекту привязано оборудование-счётчик (э/э, ХВС или ГВС) с заполненными полями brand, model и serial_number в object_equipment. Визит создан.

**Предусловие:** Визит создан. В БД загружены 89 новых записей рекомендаций.
**Шаги:**
1. Добавить задачу типа «ДГУ» (код `dgu`)
2. Открыть задачу, прокрутить до блока «Дополнительные рекомендации»
3. Проверить наличие чекбоксов рекомендаций
4. Повторить для ИБП, лифта, котла, сололифта

**Ожидаемый результат:** Для каждого нового вида оборудования отображаются типовые рекомендации, соответствующие данному коду. Чекбоксы доступны для выбора. Количество рекомендаций соответствует ТЗ (например, 5 для ДГУ, 4 для ИБП, 4 для лифтов).
**Приоритет:** Критический

## TC-192: Рекомендации — фильтрация по коду оборудования

**Предусловие:** В БД загружены рекомендации для нескольких кодов оборудования.
**Шаги:**
1. Добавить задачу типа «Кофе машина» (код `coffee`)
2. Открыть блок рекомендаций
3. Убедиться, что отображаются только рекомендации для кода `coffee`
4. Добавить задачу типа «Куллер» (код `cooler`)
5. Убедиться, что рекомендации для `cooler` отличаются от `coffee`

**Ожидаемый результат:** Рекомендации корректно фильтруются по коду оборудования. Для `coffee` отображаются 4 рекомендации (декальцинация, заварочный блок, фильтры воды, капучинатор). Для `cooler` — 3 рекомендации (дезинфекция баков, температура, прочее). Пересечений между кодами нет.
**Приоритет:** Высокий

## TC-206: Перенос оборудования — отображение в модалке

**Предусловие:** На объекте есть оборудование в разных помещениях. Инженер открыл визит.
**Шаги:**
1. Нажать «Добавить оборудование»
2. Выбрать вкладку «Уровень помещения»
3. Выбрать помещение (например, «Серверная»)

**Ожидаемый результат:** Под списком оборудования выбранного помещения отображается секция «🔄 Оборудование из других помещений (N)» с кнопками «Перенести» для каждой единицы.
**Приоритет:** Высокий

## TC-207: Перенос оборудования — кнопка «Перенести»

**Предусловие:** В секции «Оборудование из других помещений» есть хотя бы одна единица.
**Шаги:**
1. Нажать «🔄 Перенести» для единицы оборудования

**Ожидаемый результат:**
- Появляется сообщение: «Запрос на перенос отправлен. Оборудование сразу доступно в этом помещении.»
- Оборудование перемещается в список текущего помещения
- В БД создаётся `equipment_proposal` с `request_type = 'room_change'`, `status = 'pending'`
- Администратор и ТМ получают уведомление `proposal_created`

**Приоритет:** Высокий
