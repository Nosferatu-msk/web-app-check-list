## TC-033: Админ — CRUD адресов

**Предусловие:** Администратор авторизован.
**Шаги:**
1. Перейти в Админ → Адреса
2. Нажать «Добавить»
3. Заполнить поля: Город, Улица, Дом, Полный адрес, Email заказчика
4. Сохранить
5. Отредактировать созданный адрес
6. Удалить созданный адрес

**Ожидаемый результат:** Все CRUD-операции выполнены успешно. Поиск по адресу работает.
**Приоритет:** Высокий

## TC-034: Админ — CRUD видов оборудования

## TC-036.1: Админ — продуктовые метрики

**Предусловие:** В системе есть записи в audit_log (пользователи выполняли действия: создание визитов, загрузка фото, завершение визитов).
**Шаги:**
1. Войти как администратор
2. Перейти в Админ → Метрики (`/admin/metrics`)

**Ожидаемый результат:**
- Отображаются 4 карточки: DAU (сегодня + среднее), WAU (7 дней), MAU (за период), Retention (%)
- Линейный график DAU по дням отображается (Recharts LineChart)
- Блок «Активность по ролям» показывает разбивку engineer/tm/admin с процентами
- Блок «Топ-10 действий» показывает таблицу с прогресс-барами
- Переключатель периода (7 / 30 / 90 дней) пересчитывает все метрики
- Login НЕ учитывается в метриках (только бизнес-действия)

**Приоритет:** Средний

## TC-036.3: Валидация — блокировка placeholder-спецсимволов

**Предусловие:** Инженер заполняет задачу.
**Шаги:**
1. В поле «Изготовитель» ввести `.` (точка)
2. В поле «Модель» ввести `-` (дефис)
3. В поле «Серийный номер» ввести `_` (подчёркивание)
4. Попытаться сохранить задачу

**Ожидаемый результат:** Ошибки валидации: «Изготовитель: указан некорректный ответ», «Модель: указан некорректный ответ», «Серийный номер: указан некорректный ответ». Сохранение заблокировано.

**Приоритет:** Средний

## TC-134a: Админ — фильтры и редактирование в «Оборудовании объектов»

**Предусловие:** Администратор авторизован. На объектах есть оборудование разных типов, в т.ч. записи без помещения (roomTypeCode = null).
**Шаги:**
1. Перейти в Админ → Оборудование объектов
2. Выбрать объект из списка
3. В фильтре «Тип оборудования» выбрать тип (например, «Прибор учёта э/э»)
4. В поле «Марка» ввести текст (например, «Инкотекс»)
5. В поле «Модель» ввести текст (например, «Меркурий»)
6. Нажать «Сбросить»
7. Нажать «Редактировать» на записи без помещения (roomTypeCode = null)
8. Изменить марку или модель, нажать «Сохранить»

**Ожидаемый результат:** Таблица фильтруется по каждому параметру (серверная фильтрация). Фильтры комбинируются. После нажатия «Сбросить» все поля фильтров очищаются визуально (Select сбрасывается, Input пустые), выборка данных обновляется. Редактирование записи с roomTypeCode = null проходит без ошибки валидации (400).
**Приоритет:** Средний

## TC-136: Soft delete адреса

**Предусловие:** Администратор авторизован. Адрес используется в визитах.

## TC-167: Админ — управление специализацией инженера

**Предусловие:** Администратор авторизован.
**Шаги:**
1. Открыть Админ-панель → Пользователи
2. Нажать «Добавить», выбрать роль «Инженер»
3. Убедиться, что отображается блок «Специализация» с чек-боксами ВиК и ИСЖ
4. Убедиться, что ИСЖ отмечен по умолчанию
5. Отметить ВиК, снять ИСЖ
6. Сохранить
7. Открыть созданного пользователя на редактирование
8. Убедиться, что чек-боксы отражают сохранённые значения

**Ожидаемый результат:**
- Блок «Специализация» отображается только при роли «Инженер»
- По умолчанию отмечена ИСЖ
- Значения сохраняются и корректно отображаются при редактировании
**Приоритет:** Высокий

## TC-167a: Админ — блок «Специализация» отображается сразу при создании инженера

**Предусловие:** Администратор авторизован.
**Шаги:**
1. Открыть Админ-панель → Пользователи
2. Нажать «Добавить» (открыть модальное окно создания нового пользователя)
3. Не меняя роль (по умолчанию — «Инженер»), проверить наличие блока «Специализация»
4. Убедиться, что чек-боксы ВиК, ИСЖ, ГПМ, ДГУ, ИБП отображаются и доступны для выбора
5. Убедиться, что чек-бокс ИСЖ отмечен по умолчанию

**Ожидаемый результат:**
- При открытии модального окна создания пользователя блок «Специализация» отображается сразу (роль по умолчанию — «Инженер»)
- Все 5 чек-боксов специализаций доступны (не disabled)
- ИСЖ отмечена по умолчанию, остальные сняты
- Валидация работает: можно снять все чек-боксы и получить ошибку «Выберите хотя бы одну специализацию»
**Приоритет:** Высокий

## TC-169: Админ — поиск пользователей

**Предусловие:** Администратор авторизован. В системе есть пользователи с разными ФИО и email.
**Шаги:**
1. Открыть Админ-панель → Пользователи
2. Ввести в строку поиска «иван»
3. Дождаться обновления таблицы (debounce 300ms)
4. Очистить поиск крестиком
5. Ввести «@comp»

**Ожидаемый результат:**
- Поиск «иван» находит пользователей с «Иван» в ФИО (case-insensitive)
- Поиск «@comp» находит пользователей с email, содержащим «@comp»
- Таблица обновляется в реальном времени
- Лимит: не более 50 записей
**Приоритет:** Высокий
