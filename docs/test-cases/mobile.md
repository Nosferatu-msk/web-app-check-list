## МОДУЛЬ: Авторизация и безопасность

### TC-MOB-001: Вход по логину и паролю (первый вход)

**Предусловие:** Пользователь `engineer@example.com` / `engineer123` существует. Приложение установлено, первый запуск.
**Шаги:**
1. Запустить приложение
2. На экране логина ввести email: `engineer@example.com`
3. Ввести пароль: `engineer123`
4. Нажать «Войти»

**Ожидаемый результат:**
- Успешный вход, переход на главный экран (список визитов)
- Отображается предложение настроить биометрию
- Refresh token сохранён в Secure Store

**Приоритет:** Критический

---

### TC-MOB-002: Настройка биометрии после первого входа

**Предусловие:** Инженер выполнил первый вход. На устройстве настроен отпечаток пальца.
**Шаги:**
1. На экране предложения биометрии нажать «Включить»
2. Подтвердить отпечаток пальца

**Ожидаемый результат:**
- Биометрия активирована
- При следующем запуске — экран разблокировки по отпечатку (не экран логина)
- В профиле — переключатель «Биометрия» в положении ВКЛ

**Приоритет:** Критический

---

### TC-MOB-003: Вход по биометрии (повторный запуск)

**Предусловие:** Биометрия настроена. Приложение было закрыто (не свёрнуто).
**Шаги:**
1. Запустить приложение
2. Приложить палец к сканеру / посмотреть на камеру (Face Unlock)

**Ожидаемый результат:**
- Успешная разблокировка, переход на главный экран
- Сессия и данные сохранены (визит не потерян)

**Приоритет:** Критический

---

### TC-MOB-004: Вход по PIN-коду (биометрия недоступна)

**Предусловие:** Биометрия настроена. PIN-код установлен.
**Шаги:**
1. Запустить приложение
2. На экране разблокировки нажать «Ввести PIN»
3. Ввести корректный PIN-код

**Ожидаемый результат:** Успешная разблокировка, переход на главный экран.
**Приоритет:** Высокий

---

### TC-MOB-005: Неверный PIN-код

**Предусловие:** PIN-код установлен.
**Шаги:**
1. На экране разблокировки нажать «Ввести PIN»
2. Ввести неверный PIN-код

**Ожидаемый результат:** Ошибка «Неверный PIN-код». Экран разблокировки остаётся.
**Приоритет:** Высокий

---

### TC-MOB-006: Auto-lock при переходе в фон

**Предусловие:** Инженер авторизован, приложение активно.
**Шаги:**
1. Свернуть приложение (кнопка Home)
2. Подождать 5 минут
3. Развернуть приложение

**Ожидаемый результат:**
- Экран разблокировки (биометрия / PIN)
- Данные и открытый визит сохранены
- При успешной разблокировке — возврат к экрану, на котором был инженер

**Приоритет:** Критический

---

### TC-MOB-007: Auto-lock — менее 5 минут (не блокируется)

**Предусловие:** Инженер авторизован.
**Шаги:**
1. Свернуть приложение
2. Подождать 3 минуты
3. Развернуть приложение

**Ожидаемый результат:** Приложение сразу активно, экран разблокировки не показывается.
**Приоритет:** Высокий

---

### TC-MOB-008: Автоматическое обновление access token

**Предусловие:** Инженер авторизован. Access token истекает через 15 минут.
**Шаги:**
1. Работать с приложением > 15 минут
2. Выполнить действие, требующее API-запроса (открыть визит)

**Ожидаемый результат:**
- Access token автоматически обновлён через refresh token
- Инженер не видит экран логина
- Данные загружены корректно

**Приоритет:** Критический

---

### TC-MOB-009: Истечение refresh token

**Предусловие:** Refresh token истёк (7 дней).
**Шаги:**
1. Запустить приложение после истечения refresh token

**Ожидаемый результат:** Экран логина. Необходим повторный вход по логину/паролю.
**Приоритет:** Высокий
